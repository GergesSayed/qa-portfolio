# Bug Report: BUG-001

Self-made portfolio sample. The application under test is the public practice site Swag Labs (https://www.saucedemo.com). Tested manually by Girgis Saied on 25 Nov 2026.

| Field | Details |
| --- | --- |
| Title | All products show the same image when logged in as problem_user |
| ID / Severity / Priority | BUG-001 / Medium / Medium |
| Environment | Chrome (desktop), https://www.saucedemo.com, 25 Nov 2026 |
| Test data | Username: problem_user, Password: secret_sauce |
| Related test case | TC-08 (Fail). TC-07 (standard_user) passes. |

## Steps to reproduce

1. Open https://www.saucedemo.com
2. Log in as problem_user / secret_sauce
3. Look at the product images on the Products page

## Expected result

Each of the 6 products shows its own product image, as with standard_user.

## Actual result

All 6 products show the same photo of a dog (image file `/assets/sl-404-...jpg`). Product names, prices and descriptions are correct. With standard_user the 6 images are all different.

## Impact

Customers cannot tell products apart by picture, which hurts buying decisions.

## Note

Sauce Labs created problem_user to contain bugs on purpose, so this is a known practice defect. It is reported here only to show the bug-report format.
